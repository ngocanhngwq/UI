# Class Management Web UI (Digital Student Handbook)

A front-end web application designed as a digital version of the traditional student handbook ("Sổ tay học sinh"), enabling parents and teachers to track class schedules, student/teacher directories, conduct records, grades, and rankings.

🔗 **Live Demo:** [https://ngocanhngwq.github.io/UI/](https://ngocanhngwq.github.io/UI/)

## Features
* **Overview (`index.html`):** Product introduction, feature guide, and account sign-up modal.
* **Teacher & Student Directories:** Tabular management views with live search and CRUD UI controls.
* **Interactive Timetable:** Weekly class schedule with detailed subject popups.
* **Rules & Conduct Tracking:** Class discipline guidelines and behavioral records.
* **Grades & Rankings:** Google Charts visualizations summarizing grade distributions and 5-month subject progress.
* **Feedback Portal:** Dedicated settings and feedback submission interface.

## Tech Stack
* **HTML5 & CSS3** – Modular stylesheets (`common`, `layout`, `components`, `page`)
* **JavaScript & jQuery 3.6** – DOM manipulation, live search, and interactive modals
* **Google Charts** – Interactive bar, pie, and combo charts
* **Assets** – Google Sans typography & FontAwesome 5 icons

## Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/ngocanhngwq/UI.git
   ```
2. Open `index.html` directly in your browser (or launch with VS Code Live Server).
